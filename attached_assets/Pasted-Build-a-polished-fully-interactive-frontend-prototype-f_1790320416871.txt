Build a polished, fully interactive frontend prototype for an **AI-Powered Mobile Urban Intelligence Platform** based on SIH Problem Statement 26124.

IMPORTANT:

* This is a **frontend prototype/demo**, not a production backend.
* Use realistic hardcoded/mock data and simulated AI behavior.
* Do NOT build actual computer-vision models, real federated-learning infrastructure, or a production database.
* However, the UI and workflows must represent the underlying concepts accurately.
* Clearly label simulated/demo values where appropriate.
* The application must feel like a real deployable urban-intelligence product, not a generic AI dashboard.
* The prototype city is **Mumbai, India**.
* Do not use Figma. Build the actual interactive web application in Replit.
